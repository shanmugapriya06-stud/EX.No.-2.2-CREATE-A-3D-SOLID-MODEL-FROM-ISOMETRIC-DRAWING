## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

# PROCEDURE :

1. First, open Autodesk Fusion 360 and create a new design. Select the Top view (XY Plane) and click on Create Sketch to enter the sketching area..Draw a horizontal reference line from the centre point. Mark two points on the line with a distance of 56 mm between them. These points are used to locate the centres of the two circular features at the ends of the base plate

<img width="633" height="668" alt="Screenshot 2026-11-23 214342" src="https://github.com/user-attachments/assets/7d6dfcbb-5491-4510-99a1-d124ed12d98c" />


2. At each marked point, use the Circle – Center Diameter Circle tool to draw a circle of Ø36 mm (R18). Inside each circle, draw another concentric circle of Ø16 mm. Apply the required dimensions using the Sketch Dimension tool.

<img width="535" height="425" alt="Screenshot 2026-11-24 002126" src="https://github.com/user-attachments/assets/a9bb7db5-74d0-4683-ae8e-725a07d738f2" />


3. Use the Line tool to join the two Ø36 mm circles with lines on the top and bottom sides. Apply the Tangent constraint to make the lines meet the circles properly.

4. Use the Trim tool to remove the unwanted portions of the circles and lines inside the profile. Make sure that a closed slot-shaped base outline with two Ø16 mm holes is obtained. Then click on Finish Sketch.

5. Select the base profile and click on the Extrude tool. Enter 8 mm as the extrusion distance to create the base plate with 8 mm thickness.

6. Select the top face of the base plate and create a new sketch. Draw a rectangle of 40 mm × 10 mm for the vertical block and position it at a distance of 10 mm from the edge of the base. Finish the sketch and extrude it upward to a height of 32 mm.

<img width="362" height="362" alt="Screenshot 2026-11-23 214308" src="https://github.com/user-attachments/assets/67712e4b-0916-49cf-bfd9-9ed46dd03479" />

7. Select the top face of the vertical block and create a new sketch. Using the Circle – Center Diameter Circle tool, draw a circle of Ø30 mm towards the left side, at a distance of 32 mm from the rectangle. Use the Sketch Dimension tool to set the required distance and diameter.

8. Use the Line tool to connect the circle and the rectangle on the top and bottom sides. Apply the Tangent constraint so that the lines meet the circle smoothly. Use the Trim tool to remove the unwanted portions and click on Finish Sketch. Extrude the closed profile by 10 mm to form the horizontal arm and circular boss.


<img width="535" height="425" alt="Screenshot 2026-11-24 002126" src="https://github.com/user-attachments/assets/8d1880c8-40b4-445f-9d73-9fb58a2d965b" />

9. Select the top face and create a new sketch. Draw a concentric circle of Ø20 mm at its centre. Use the Extrude tool with the Cut option to create the through hole.

10. Select the side face of the vertical block and create a new sketch. Draw a right-angled triangle connecting the base plate and the vertical block to form the supporting rib. Set the rib thickness to 12 mm and use the Extrude tool to complete it.

11. Check all the dimensions, including the Ø16 mm and Ø20 mm holes, 8 mm base thickness, 32 mm height and the position of the rib. After checking everything, save the completed model with the required file name.

12. After completing the 3D model, switch to the Drawing workspace and create the drawing in ISO standard format. Add the Front, Top, Side and Isometric views. Apply the required dimensions, check the final views and save the drawing.
